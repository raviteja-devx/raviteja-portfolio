RAVITEJA PORTFOLIO — STARTER PROJECT

FILES
- index.html: the website content
- style.css: colors, layout, responsive design and animations
- script.js: mobile menu, scroll progress and reveal animations

HOW TO OPEN ON WINDOWS
1. Extract this ZIP to Documents or Desktop.
2. Install Visual Studio Code from https://code.visualstudio.com/
3. Open VS Code -> File -> Open Folder -> select raviteja-portfolio-starter.
4. Open index.html. For the first preview, double-click index.html in File Explorer.
5. Recommended: install the "Live Server" extension in VS Code, right-click index.html,
   choose "Open with Live Server". Save files with Ctrl+S; the browser refreshes.
